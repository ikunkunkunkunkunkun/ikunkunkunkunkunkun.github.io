# Project Status

- Current goal: Publish a standalone contribution-calendar page with a snake that remains visible when switching GitHub contribution years.
- Completed work: Added `/contributions/` with a dark GitHub-style calendar, 2023–2026 year selector, animated purple snake, pause/replay controls, date tooltips, and mobile horizontal scrolling. Added a GraphQL data exporter and daily GitHub Actions refresh workflow. Seeded year JSON from GitHub GraphQL using the authenticated account token.
- Key technical decisions: Native GitHub profile contribution controls cannot host custom JavaScript, so the interactive version is a separate GitHub Pages route linked from the profile README. The public JSON contains only dates and contribution counts; the token is stored as a repository Actions secret. Data source is GitHub's `contributionCalendar` for each calendar year, so totals can differ from GitHub's rolling past-year total.
- Core file changes: `contributions/index.html`, `contributions/style.css`, `contributions/app.js`, `contributions/scripts/update-data.mjs`, `contributions/data/*.json`, `.github/workflows/contribution-data.yml`.

The page rendered in headless Chrome at 1440×760 and 1200×700; the 2025 query-string selection displayed its 98-count calendar, visible snake and active 2025 year button.
